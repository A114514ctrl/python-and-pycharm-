# 操作说明

> 项目：CIFAR-10 图像分类（改进 CNN）　环境：Windows + Python 3.10 + PyTorch
> 本文档说明“怎么把这个项目跑起来”，分 **PyCharm** 与 **双击 bat** 两种方式，最后附 GitHub 上传提示。

---

## 一、首次准备（只做一次）

### 1. 安装依赖

打开命令行（或 PyCharm 底部 Terminal），在项目根目录执行：

```bash
pip install -r requirements.txt
```

> PyTorch 体积较大，国内建议加镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
> 纯 CPU 机器也能跑；有 NVIDIA 显卡时会自动使用 GPU。

### 2. 生成数据集

```bash
python code/01_prepare_dataset.py
```

会下载 CIFAR-10（约 140MB）并导出成 `dataset/train|val|test/<类别>/*.png`，
同时生成 `results/dataset_distribution.png`（类别分布）、`dataset_preview.png`（样本预览）、
`augmentation_preview.png`（增强预览）。
划分规则：官方 50000 张训练图按类 9:1 分层抽样 → train 45000 / val 5000；官方 10000 张测试图 → test。

## 二、方式 A：PyCharm 里操作

1. `File → Open` 选择本项目文件夹；
2. 右下角确认解释器为 **Python 3.10**（`Settings → Project → Python Interpreter` 可切换）；
3. 按 **`Alt + F12`** 打开底部 Terminal（注意：**不要用 Run 窗口**，它不接收文件拖拽），
   然后 `cd code` 进入代码目录；
4. 依次执行：

```bash
# ① 看数据清单（10 秒，不训练、不写文件）
python 03_train.py --model improved --epochs 24 --dry-run

# ② 测试集评估（约 40 秒）→ 输出测试准确率、每类精确率/召回率/F1
python 04_test_and_visualize.py --model improved

# ③ 现场预测（拖图进 Terminal 回车；或直接回车弹出选图窗口；或给路径）
python 05_predict.py
python 05_predict.py --image "D:\pics\cat.jpg"
python 05_predict.py --folder "D:\pics"      # 批量，输出三行结果图

# ④ 生成 Word 实验报告（约 30 秒）
python 06_make_report.py
```

**训练自己跑一遍（可选）**

```bash
python 03_train.py --model improved --epochs 24 --no-eval-test      # 完整 24 轮（CPU 约 25 分钟）
python 03_train.py --model baseline --epochs 20 --no-eval-test      # 基线 20 轮（约 7 分钟）
python 03_train.py --model improved --epochs 2 --no-eval-test --tag _demo   # 试跑 2 轮，不覆盖正式结果
```

- `--no-eval-test`：训练过程中不评估测试集（测试集只在 `04` 里用一次，符合“三集独立”的要求）；
- `--tag _demo`：把权重/日志写成 `*_demo*`，**不覆盖**正式结果；
- 每轮会打印 `[Epoch 01/24] train_loss=… train_acc=… | val_loss=… val_acc=… | 51.6s  <-- 保存最优模型`。

## 三、方式 B：双击 bat（不用敲命令）

`scripts/` 下 7 个 bat，双击即可（会先自动定位到项目根目录）：

| bat | 作用 | 是否改动正式结果 | 需要数据集 |
| --- | --- | --- | --- |
| `run_inventory.bat` | 查看数据清单（train/val/test 张数与计划轮数） | 否 | 是 |
| `run_eval.bat` | 测试集评估，输出准确率与每类指标 | 只刷新指标与图 | 是 |
| `run_predict.bat` | 交互式预测（拖图 / 回车选图 / 粘贴路径） | 否 | 单张图不需要 |
| `make_report.bat` | 重新生成 Word 实验报告 | 覆盖 `report/*.docx` | 否 |
| `train_demo_2ep.bat` | 真跑 2 轮演示（`--tag _demo`） | **否**，不覆盖正式权重 | 是 |
| `train_full_24ep.bat` | 备份权重 → 训练 24 轮 → 评估 → 重生成报告 | **是**（会先自动备份到 `weights/backup/`） | 是 |
| `watch_log.bat` | 实时滚动显示 `results/train_log_improved.txt` | 否（只读） | 否 |

> 首次双击若提示找不到 `code` 文件夹，说明 bat 不在仓库根目录下运行，请确认它在 `scripts/` 里。

## 五、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `ModuleNotFoundError: torch` | 依赖没装 → `pip install -r requirements.txt`；或 PyCharm 解释器选错 |
| 报“找不到 dataset / 找不到路径” | 还没生成数据集 → 先跑 `python code/01_prepare_dataset.py` |
| 报“找不到权重” | `weights/improved_best.pth` 丢失 → 重新训练，或从备份/发行包取回 |
| 拖图没反应 | PyCharm 的 Run 窗口不接收拖拽 → 用 Terminal，或直接回车弹选图窗，或 `--image` |
| 图表中文变成方框 | 系统缺 `Microsoft YaHei` → 把 `02/04/05` 里的字体名改成 `SimHei` |
| bat 一闪而过 | 正常应停在“请按任意键继续”；若闪退，右键“以管理员身份运行” |
| 在 PyCharm 直接点 ▶ Run 跑 `03_train.py` | 不带参数会被“防误触保护”拦下（防止误覆盖权重），请用 Terminal 带参数运行 |

## 六、上传 GitHub 提示

1. 项目里已放 `.gitignore`，默认忽略 `data/`、`dataset/`、`data_raw/`、`results/`、`__pycache__/`，
   **不会把 6 万张图片和中间产物传上去**；
2. 首次上传（在项目根目录）：

```bash
git init
git add .
git commit -m "Initial commit: CIFAR-10 image classification with improved CNN"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

3. 想保留训练好的权重一起上传：把 `.gitignore` 里的 `weights/*.pth` 注释掉再提交（两个文件共约 2MB）；
4. 建议在仓库首页填写 About 简介与 Topic（如 `pytorch`、`cifar10`、`image-classification`），
   并确认没有把 `data/` 目录一起提交（可用 `git status` 检查）。
